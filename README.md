# タービュレントディスプレイス（Turbulent Displace）
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](#)
[![.NET](https://img.shields.io/badge/.NET-10.0-blue.svg)](#)
[![Downloads](https://img.shields.io/github/downloads/leftcontroller0518/TurbulentDisplace/total)](https://github.com/leftcontroller0518/TurbulentDisplace/releases/latest)

YMM4用の映像エフェクトプラグインです。Improved Perlin NoiseとfBM（Fractal Brownian Motion）を使用して、映像を水面や熱気のように不規則に歪ませます。Direct2Dピクセルシェーダーで処理するため、フレームごとにアニメーションさせることもできます。

## パラメータ
### 量
映像を歪ませる強さをピクセル単位で指定します。

値が大きいほど、元の映像から大きくずれます。

### サイズ
ノイズの大きさを指定します。

- 小さい値: 細かく複雑な歪み
- 大きい値: 大きくゆったりした歪み

### 複雑度
fBMで使用するノイズのオクターブ数を指定します。

値を大きくすると歪みの細部が複雑になりますが、処理負荷も増加します。

### 展開
ノイズ空間を移動させます。

キーフレームを設定することで、歪みパターンを時間経過に合わせて変化させられます。

### オフセットX / オフセットY
ノイズ空間の位置を横方向・縦方向に移動させます。

歪みのパターンを変更したい場合に使用します。

### 乱数シード
ノイズパターンの種類を変更します。

同じパラメータでも、異なる歪みパターンを生成できます。

### 方向
変位させる方向を指定します。

- 両方向: 横方向・縦方向の両方に歪ませます
- 水平: 横方向だけに歪ませます
- 垂直: 縦方向だけに歪ませます
- 放射: 中心から外側へ向かう方向に歪ませます

### 端の固定
映像の端に近づくほど歪みを弱めます。

映像の境界を維持したい場合に使用します。

### 端の幅
「端の固定」が影響する範囲を指定します。

値が大きいほど、映像の広い範囲で歪みが弱くなります。
